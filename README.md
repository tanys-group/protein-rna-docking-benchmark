The consolidated protein–RNA docking benchmark consists of 235 test cases.
The protein-rna-docking-benchmark.zip file contains directories named according to the PDB code of the corresponding protein–RNA complex. Each of these directories contains an input PDB file for the protein and an input PDB file for the RNA.
The Excel file contains details of the input PDB structures and reference protein–RNA complex PDB structures.
The native1.zip and native2.zip files contain the PDB structures of the reference protein–RNA complexes.
