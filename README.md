The consolidated protein-RNA docking benchmark consists of 235 test cases.
The protein-rna-docking-benchmark.zip file contains 235 directories named according to the PDB code of the corresponding protein-RNA complex. Each of these directories contains an input PDB file for the protein and an input PDB file for the RNA.
The native.zip file contains the reference protein-RNA complex structures.
The Excel file contains details of the input structures and reference complex structures.
